## 이후 백엔드 연결 작업 원칙

1. 프론트 문구와 화면 흐름을 임의로 바꾸지 않는다.
2. 질문/결과/점수 계산 데이터는 `src/data/coolbti.ts` 기준을 유지한다.
3. `/admin` UI는 데이터 조회/수정/삭제 연결만 보강한다.
4. Supabase `service_role` key는 Vercel 서버리스 API 환경변수에만 넣는다.
5. `VITE_` 환경변수에는 공개 가능한 anon key와 URL만 넣는다.
6. 기존 `main`은 Streamlit 앱 히스토리이므로, 별도 승인 없이 force push하지 않는다.

## 필요한 환경변수

## 복구 방법

현재 프론트 기준선으로 돌아가야 하면:

```bash
git switch backup/frontend-baseline-20260515
```

또는 태그 기준으로 확인:

```bash
git switch --detach frontend-baseline-2026-05-15
```

현재 작업 브랜치에서 특정 파일만 기준선 상태로 되돌려야 할 때는 먼저 변경 내용을 확인한 뒤, 필요한 파일만 선택적으로 복원한다.

## Vercel 배포 기준

현재 최신 축제 앱은 `codex/festival-coolbti` 브랜치에 있다.

Vercel에서 최신 화면이 안 보이면 먼저 확인할 것:

1. Project `festival-coolbti`
2. Settings -> Git
3. Production Branch가 `codex/festival-coolbti`인지 확인
4. Build Command: `npm run build`
5. Output Directory: `dist`
6. Install Command: `npm install`

`main`을 production으로 쓰려면 기존 Streamlit main을 덮어쓰는 작업이므로 별도 명시 승인이 필요하다.
